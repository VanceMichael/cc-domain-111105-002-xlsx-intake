# 数据格式

工作簿使用标准 OOXML 包结构，根关系（`_rels/.rels`）指向 `xl/workbook.xml`，工作表通过 `xl/_rels/workbook.xml.rels` 定位；关系目标按包内相对路径解析，越出包根或指向外部 URL 的关系一律拒收。mapping.json 的 kind 区分 identifier、decimal、date 和 text，group 指定分组列。纯补零样式在示例中使用 000000。样本含稀疏列、富文本 sharedStrings、公式缓存和两套日期基准。ZIP 检查器（src/source.mjs）提供目录摘要，不解释工作表内容；接入模块（src/intake.mjs）在其上做完整解压与逐字段解释。

所有企业、设备、记录和站点均为虚构。二进制原件的长度及摘要见 fixtures/manifest.json，运行时不需要访问这些网址。

## 接入解释约定

- **列定位**：列号只取自单元格 `r` 属性（如 `r="D3"`），不依赖 XML 节点出现顺序；范围外和映射外的列不输出。
- **identifier**：数值单元格仅在样式命中纯补零自定义格式（格式代码去字面量后首段仅含 `0`/`?` 且含 `0`）时按宽度前补零；字符串单元格（sharedStrings、inlineStr、公式 str）原样保留，因此超长编号不会经过浮点。
- **decimal**：保存十进制原文 `raw` 与按映射 scale（10 的整数幂）缩放后的精确定点字符串 `scaled`；缩放用 BigInt/字符串移位完成，不先经过 Number。可整除时另附 `exactInteger`。
- **date**：按工作簿 `date1904` 选择 1900/1904 基准，输出 UTC ISO 字符串与原始序号；1900 基准的序号 60（虚构 1900-02-29）状态为 unavailable，原因码 DATE_SERIAL_60。
- **text**：sharedStrings 拼接富文本全部 `t` 段，inlineStr 读取 `is/t`，索引越界按字段错误隔离。
- **合并区域**：只接受单列纵向合并；横向合并报 MERGE_SHAPE。与映射范围相交的合并若不在 group 列上，报 MERGE_NOT_GROUP，避免指标值被向下填满；group 列的后续空白行从锚点单元格取值并标注 anchorRef/merge/filledFromMerge，锚点缺失为字段错误。
- **公式**：本机不求值。`fullCalcOnLoad=1`、无缓存、缓存类型不符映射、缓存为错误（t="e"）均为 pending 并带原因码；有合法缓存时 status=ok、cached=true 且保留公式原文。
- **空值与错误**：单元格缺失或无值为 empty/BLANK；t="e" 非公式错误为 error/ERROR_VALUE。单字段错误只隔离该字段并反映在行状态中；压缩包不完整、关系越界、同名工作表、合并违规或超过限额属于整批拒收（accepted=false），不得进入正式批次。
- **接入身份**：intakeId = SHA-256(`xlsx-intake:` + 原件 SHA-256 + `:` + 映射版本 + `:` + 映射规范化摘要)。同一文件重送得到同一身份可查回原结果；映射换版本或改内容产生独立身份。

## 限额

extractZip 与工作表解析支持限额：maxEntries、maxExpandedBytes、maxExpandedEntryBytes、maxCells（CLI 参数 --max-entries/--max-bytes/--max-entry-bytes/--max-cells）。超限即整批拒收，原因码 LIMIT_EXCEEDED 或 ZIP_INVALID。
